# Band Name Generator

## Overview
The Band Name Generator is a fun and interactive Python project that helps users come up with creative band names by combining their personal inputs. This project is designed to provide an engaging way to learn the basics of Python programming, including input handling and string concatenation.

## How It Works
1. The program greets the user with a welcome message.
2. It prompts the user to enter the name of the city where they grew up.
3. Next, it asks for the name of a pet.
4. Finally, it combines these inputs to generate a unique band name and displays it to the user.

### Example Output
```
Welcome to the Band Name Generator
Which city did you grow up in?
New York
What is the name of a pet?
Buddy
Your band name could be New York Buddy
```

## Features
- **User Input**: Interactive prompts for personalized user input.
- **Dynamic Output**: Generates a unique band name based on user-provided data.
- **Simple and Fun**: Easy to use and understand, making it perfect for beginners.

## Learning Objectives
- Understanding Python basics, including:
  - Printing to the console.
  - Taking input from the user.
  - Concatenating strings.
- Building a simple interactive application.
- Enhancing problem-solving skills through coding.

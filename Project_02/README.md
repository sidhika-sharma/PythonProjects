# Tip Calculator

## Overview
The Tip Calculator is a simple and practical Python project designed to help users easily calculate the amount each person needs to pay when splitting a bill, including a tip. This project is ideal for beginners to practice Python programming concepts like user input, arithmetic operations, and formatting output.

This project is the second in the 100 Days of Python series, where I create daily projects to solidify my Python skills and learn new concepts.

## How It Works
1. The program greets the user with a friendly message.
2. It asks the user to provide three inputs:
3. The total bill amount in dollars.
4. The tip percentage they want to give (e.g., 10%, 12%, or 15%).
5. The number of people sharing the bill.
6. Using these inputs, the program calculates:
7. The total tip amount.
8. The overall bill amount (including the tip).
9. The amount each person needs to pay.
10. The final amount each person should pay is rounded to two decimal places and displayed to the user.


### Example Output
```
Welcome to the tip calculator!  
What was the total bill? $100  
what percentage tip would you like to give?10 12 15 15
How many people to split the bill? 4  
Each person should pay: $28.75  
```

## Features

- **User-Friendly Input**: Accepts interactive inputs from users.
- **Dynamic Calculation**: Automatically computes the total bill and per-person amount based on user inputs.
- **Precision**: Rounds the result to two decimal places for clarity and accuracy.
- **Real-World Application**: Helps users calculate shared expenses with ease.
